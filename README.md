# vegans-union

A worldwide directory connecting vegans, vegetarians, and animal lovers with opportunities to help animals and discover animal-friendly organizations, brands, and products.

## Project status

The project is in planning. The features below describe the intended direction, not an implemented application.

## Planned features

- Discover animal rescues, sanctuaries, charities, and relevant farms.
- Find volunteering opportunities through official application links.
- Explore curated brands and products, distinguishing vegan products from entirely vegan brands.
- Search by country, city, and category.
- Suggest listings and report outdated information through moderated forms.
- Browse without registration and save favorites on your device.
- Install the website as a progressive web app.

The initial interface will be in English, with worldwide listings growing from a curated collection. Listings will include sources and review dates. Source review does not certify safety or animal-welfare practices. Applications and donations use organizations' official websites.

## Technology direction

Angular and TypeScript frontend, Java and Spring Boot backend, and PostgreSQL database. Supported versions will be selected before implementation.

## Initial scope

The first release focuses on discovery and moderated contributions. Chat, visitor accounts, public reviews, payment processing, and automated recommendations are outside the initial scope.

## Privacy

Browsing will not require an account. Any future optional research participation will have separate participant information and an appropriate review process before recruitment.

Do not submit personal information, participant records, credentials, or confidential planning material through public issues or pull requests.
